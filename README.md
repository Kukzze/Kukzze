### 🚀 What I'm building

**[Excel Masters](https://www.excelmasters.in/)**: a hands-on spreadsheet training platform. Formulas run in the browser on a deterministic AST engine, so the AI explains the math but never makes it up. The engine is open source as [`formula-core`](https://github.com/ExcelMasters-in/formula-core).

**[Chic Builder](https://chic-builder.vercel.app/)**: a free AI workout PWA with progressive-overload tracking, daily tasks and ranked leaderboards. It works offline in the gym. The training math is in [`chic-core`](https://github.com/ChicBuilder/chic-core).
